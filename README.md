# Student Data Cleaning and Visualization

## Project Description
Data cleaning, exploratory data analysis and visualization
were performed on a student performance dataset using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
Student performance dataset containing 395 records
and 33 attributes.

## Tasks Performed
- Data cleaning
- Missing value analysis
- Duplicate detection
- Outlier detection
- Exploratory Data Analysis
- Data visualization
- Correlation analysis
- Standard scaling

## Visualizations
- Gender distribution
- Age distribution
- Grade distribution
- Box plots
- Histograms
- Correlation heatmap

## Conclusion
The student dataset was successfully cleaned and analyzed.
Several patterns and relationships between student characteristics
and academic performance were explored using visualization.
